# 使用說明

## 介面語言

右上角語言選單提供「繁體中文」「简体中文」「English」，也可在「資料與設定 → 介面語言」切換。選擇即時生效，重新開啟後保留；首次開啟預設繁體中文。介面採書面語，VPIP、RFI、3-bet 等 Poker 術語保留英文。

語言只改變介面標籤、說明、已知診斷訊息與數字／日期顯示，不改變篩選值、統計定義、金額或來源時區。手牌原文、玩家名稱、來源名稱、筆記、標籤與檔案路徑保留原內容；未知引擎診斷保留原始技術文字。語言偏好存在此裝置的介面儲存區，不包含於 SQLite 資料庫備份。

## 匯入來源

同一批牌譜固定使用同一個 profile；去重鍵為 `(profile, Hand ID)`。同 ID、同原文會略過；原文不同會保留衝突，不覆蓋既有手牌。跨 profile 代表不同資料來源，可能重複計算同一牌局，請勿把相同 ZIP 另開 profile 重匯。

TXT 需 UTF-8；ZIP 串流讀取 TXT，不解壓至任意路徑。資料夾會遞迴尋找 TXT／ZIP。單手原文上限 1 MiB；超限、無法解碼或不支援格式有明確錯誤。匯入進度以檔案完成數及掃描嘗試手數顯示，續匯會重掃未完成檔案，因此「掃描／重複」可包含重試；「新增」與資料庫唯一手數不重複。

暫停在安全批次邊界生效。重啟後未完成工作顯示中斷，可續匯；已提交交易保留。來源檔案需要仍在原位置且內容穩定。更改來源 Hero、品牌或時區須建立新 profile，避免混合解析規則。

## 報表與統計

共用篩選可按來源、牌局類型、盲注、位置及進階條件縮小範圍。「儲存篩選」可重用；圖表旁圖釘固定一組自身結果，變更篩選後比較手數、盈虧與 bb/100。

盈利走勢為每日累積；Showdown 與 Non-showdown 可獨立切換。美元現金流使用精確整數儲存，bb/100 按每手對應 BB 換算。圖表／顯示比例採浮點，不用於金額帳本。

核心統計直接顯示 13 項，分為翻前（VPIP、PFR、RFI、3-bet、Fold to 3-bet）、盲位防守（Blind Fold／Call／Raise）、翻後（Flop C-bet、Fold vs C-bet）、攤牌與贏池（WTSD、W$SD、WWSF）。全部沿用目前共用篩選。

每個統計都有分子、機會分母與定義。點比率或「機會」查看分母手牌；點「符合」查看分子手牌。「顯示定義」可同時展開各項計算方式；零機會顯示「—」。低樣本數不是策略結論。日期篩選與手牌清單顯示 HKT；日期分組及點入明細依來源內文日期，回放顯示原始時間與時區。

資料異常牌局預設隔離，不進核心報表；有效及隔離手數會分開。可以在進階篩選選「已隔離」或從匯入問題開啟原文。對不支援而尚未正規化的紀錄，匯入中心另外保留原文及原因。

## 矩陣、複盤與回放

13×13 上三角 suited、下三角 offsuit、對角為 pocket pair。可看手數、Net bb、bb/100 或指定行動頻率；每格 tooltip 顯示實際手數、行動次數與機會。無樣本不是 fold range。頻率模式的格子及詳情按鈕均開啟該統計的機會手牌；用「返回報表及原本篩選」可保留原模式、統計與起手牌。

回放：`←`／`→` 逐步、`Space` 播放／暫停；輸入筆記時不截取鍵盤。也可用按鈕、timeline、街道按鈕。Hero 底牌已知；對手底牌只在原文已知且相應顯牌步驟後顯示，「已知底牌」可提前顯示原文已知的牌，未知始終保持牌背。不同 runout 分開顯示，保留共用牌面。

帳本分開列投入、退注、派彩、Cashout 與 Risk。底池最後剩餘費用不再算成 Hero rake。全桌 rake、Jackpot 等只是原文項目，不代表 Hero 個人費用。

複盤工作台列出 Call 3-bet、盲位防守、C-bet 遇 Raise、River Call 等具體情境。最大贏／輸入口自動套用最大盈利／虧損排序。備註與標籤以「儲存筆記與標籤」保存；儲存期間暫停編輯，關閉未儲存筆記會提示。

對話框內可用 Tab／Shift+Tab 移動，Escape 關閉並返回原控制項。回放原文區可取得鍵盤焦點後捲動。放大或縮窄視窗時，導覽及控制會重排；寬表格保留區內橫向捲動。

## 每日學習工作台

1. **Spot Explorer**：選來源、日期、遊戲及盲注，再用 BB 面對 Open、面對 3-bet 等預設開始。進階條件包括位置、IP／OOP、決策當時底池類型、起始有效籌碼、翻牌結構、面對下注比例及完整有序行動線。行動線由第一個所選街道起逐步列出，排除目前 Hero 決策。翻牌後只收錄從翻牌起單挑的牌局。輸入名稱可儲存及重用情境。
2. **Leak Finder**：為目前情境建立目標行動、頻率上下限、最少機會及依據。未設目標不判定錯誤；樣本不足仍顯示觀察，排序優先度為零。95% Wilson 區間只是頻率區間，並非 GTO 偏差的顯著性檢定。
3. **Preflop GTO 對照**：匯入自己的 NL10 6-max 100bb Nexus `manifest.json`；TXT 檔案需保留 manifest 內的相對位置。選節點、行動及組合，看策略、實際頻率或差距。只有位置、前序行動與注碼、六人籌碼及盲注等設定匹配才納入偏差統計。可手動選其他節點作參考。所選理論模型不能證明與牌室抽水完全相同。
4. **Trainer**：從決策列或策略矩陣加入題目；預設每次最多 20 題。提交前不顯示原本行動、筆記或策略答案。翻前可分配合計 100% 的頻率，或判斷一個行動是否在來源策略中有正頻率。翻後與設定不匹配的歷史題目採自行複盤。提交後可回放、讀筆記，按理解程度選「需要再練」或「已掌握」。複習間隔為 1、3、7、14、30 天；中途關閉後可繼續同一次練習。

頻率分母是決策機會，同一手牌可有多次機會；淨結果每手只計一次，不代表該決策的 EV。來源 range 權重先按抵達節點的權重換算；來源不一致的格子標示 `?` 並排除評分。來源不提供 decision EV，因此不計算 EV 損失。

首次升級先建立安全備份，索引以小批次背景建立，可暫停／繼續。未完成時顯示覆蓋手數，報表只使用已完成索引的手牌。情境、目標、策略原文、題庫、練習紀錄均包含於 SQLite 備份，從原文重算亦保留。若牌局已移除或決策版本改變，舊題目標示不可用，需重新加入。

## All-in 調整

只計算完整帳本、HU、單底池、單 runout、底牌完整且無 Cashout／特殊結算。鎖定最後 all-in call 當刻的公共牌，未來實際 turn／river 不進 equity 輸入；剩餘發牌精確枚舉並本機快取。

每手列已完成、待計算、不適用或排除原因。圖表將適用且已完成手牌的實際結果替換成其 adjusted net；其餘保留實際結果。故名稱為「實際結果＋已完成適用牌局調整」，不是完整 EV、decision EV 或 GTO 分數。資料設定可暫停／續算。

## 備份與匯出

建立備份需選新檔名，避免靜默覆蓋。還原先建立目前資料的安全備份、驗證來源 integrity/schema，再替換；匯入時禁止還原。還原後 equity 暫停，確認資料後可續算。

「從原文重算」先備份，在獨立 SQLite 建新資料，再還原至目前 DB；筆記、標籤、已儲存篩選及無法解析的原文保留。完成前仍可讀現有資料，重算期間寫入排隊；大型 DB 需較長時間。

報表 CSV 是目前分組結果。手牌清單 CSV／HH 是目前篩選；勾選手牌後只匯出所選，單次最多 1,000 個指定 ID。不勾選時串流匯出全部符合條件手牌。全部操作留在本機。

匯入採同一來源＋Hand ID 去重；內容相同則略過，內容不同會列為衝突並保留該份原文。續匯從尚未完成的檔案重新掃描，已保存手牌仍會略過；工作中的累計掃描／重複數可包含重掃紀錄。資料問題可使用上一頁／下一頁查看，每頁最多 300 筆。

策略匯入可直接輸入本機 manifest.json 的完整路徑。
